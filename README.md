## Cài đặt
Clone
```
git clone https://github.com/MinhThongPhan/VietnameseSentimentAssistant.git
```
```
cd VietnameseSentimentAssistant
```

Cài đặt môi trường
```
python -m venv venv
```
```
venv\Scripts\activate
```

Cài đặt thư viện
```
pip install -r requirements.txt
```

Chạy ứng dụng
```
streamlit run app.py
```
